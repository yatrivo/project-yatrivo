# Yatrivo

Yatrivo is organized as a full-stack repo with the frontend app in `frontend/` and the planned backend API in `backend/`.

The `frontend/` folder contains the approved Figma-originated React app and is now the real frontend implementation source. Treat it as production code, not reference material.

## Standard Ports

- Frontend: `3000`
- Backend: `4000`

## Common Commands

```bash
npm --prefix frontend install
npm --prefix frontend run dev
npm --prefix frontend run build
```
