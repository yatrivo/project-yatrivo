# Figma Documentation

## Purpose

This directory translates the Figma design into structured implementation specifications.

## Source of Truth

Figma is the source of truth for visual and interaction design.

## Documentation Process

```text
Figma
  |
Screen analysis
  |
Component analysis
  |
Interaction analysis
  |
Implementation specification
```

## Important Rule

Do not treat a screenshot as the complete representation of a screen.

The documentation should capture:

- Structure
- Components
- States
- Interactions
- Responsive behavior
- Motion
- Navigation
- Accessibility
